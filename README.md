
# buildCEGs

<!-- badges: start -->
<!-- badges: end -->

The buildCEGs R package has been designed and developed to provide accessible software in which to manually construct chain event graphs and large event trees. It has been developed with expert-elicited models at the core of its premise, focusing on building chain event graphs from the ground up from an event tree, to a staged tree, and arriving at the CEG. CEGs may be imported directly into the software, enabling the user to produce high-quality, interactive plots of any CEG and to perform probabilistic analyses upon these. 

To strive towards maximal accessibility and interpretability, this package provides a foundation for the CEG Modelling Tool which is available as a Shiny app hosted online. This app has been built to best allow not only statisticians and probabilists, but any kind of modeller working in an applied domain, to be able to create their own chain event graph models.

This R package contains functionality to build event trees; to manipulate these event trees; to analyse these event trees; to convert these event trees into staged trees; to convert these event trees into chain event graphs; to apply evidence to these chain event graphs via the CEG probability propagation algorithm; and to calculate probability and odds ratios between sets of root-to-sink paths in the chain event graph.

To get a better idea of the full range of functionality this R package provides, see the user manual for the CEG Modelling Tool Shiny app. The user manual provides screenshots of the various interfaces within the app, and of the outputted plots of trees and CEGs as would also be produced within the R package. The user manual can be accessed here:
[CEG Modelling Tool User Manual](App%20User%20Manual/App%20User%20Manual.pdf)

The 'buildCEGs' R package can be installed from its GitHub repository, while the CEG Modelling Tool application can be accessed either through an install via GitHub or online, with the address to be updated in due course.
